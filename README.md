## 01 / What I build

I like the **whole engineering journey** — structuring messy data, designing a reliable workflow, validating a model, and building the software around it. The most interesting part isn't a model's accuracy alone; it's making the entire system useful.

```text
      raw data  ──→  processing  ──→  intelligence  ──→  real-world use
          │               │                │                  │
      acquisition       ETL / BI       ML / simulation      APIs / apps
```

My interests converge around **Data Engineering · Applied Machine Learning · Intelligent Systems**, with a growing focus on building systems that are robust beyond the notebook.
